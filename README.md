# Roopa Creations — Live Event Keepsakes

A modern, responsive web application for **Roopa Creations**, offering live fridge magnet and acrylic keychain stalls for weddings, corporate functions, college farewells, and celebrations.

## 🚀 Features

- **Live Keepsake Simulator**: Interactive preview tool for clients to test custom event titles, border frames (*Royal Gold*, *Roopa Pink*, *Midnight Dark*, *Classic White*), and product types (*Fridge Magnet* vs *Acrylic Keychain*).
- **Interactive Booking Inquiry**: Direct modal form with auto-filled WhatsApp dispatch (`+91 9019720502`).
- **Gallery Lightbox & Category Filter**: Filter photo keepsakes by *Weddings*, *Corporate*, *Farewells*, and *Parties* with full-screen lightbox preview.
- **Customer Reviews**: Dynamic review submission form powered by `localStorage`.
- **Responsive & Modern Design**: Built with Playfair Display and DM Sans typography on a warm cream aesthetic (`#fffcf8`).

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Vanilla CSS
- **Icons**: Lucide React

## 💻 Local Development

```bash
# Install dependencies
pnpm install

# Start local dev server
npm run dev
```

The application runs on `http://localhost:5173/`.
